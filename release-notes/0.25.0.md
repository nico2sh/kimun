## Sidebars views management
You can drag views from the rail to the sidebar, and you will now get a visual indicator of how the view will split, or what it will replace. This will make easier for you to customize the views in your editor so you can have all the information you care about while editing and working on your notes.

## Tabs and splits!
You can now have tabs with different notes, and on each tab you can split the editor so you can look at more than one note at a time.

## Server updates
Now you can update the semantic/AI server from the GUI, so everything in a single place.
Plus, fixed a bug when updating the server it wasn't being restarted with the new version, and now you can browser the server's config from the GUI preferences.
