## The macOS desktop app is signed, and one command installs both TUI and GUI

- **A signed macOS app.** This release has `Kimun.app` in a `.dmg` file for Apple Silicon and Intel Macs. Apple signed and checked the app (notarization), so it opens with no "unidentified developer" warning. Open the `.dmg` and drag the app to Applications.
- **One installer for both apps.** On macOS and Linux, `curl -fsSL https://kimun.2co.dev/install.sh | sh` now installs the terminal app and the desktop app. On Windows, `irm https://kimun.2co.dev/install.ps1 | iex` does the same. If the desktop app cannot be installed, the terminal app stays installed, and the script tells you why and how to try again. On a Linux machine with no display, the script skips the desktop app.
- **Choose one app.** Add `--tui` for the terminal app only, or `--gui` for the desktop app only. On Windows, use `-Tui` or `-Gui`. If you name an app, it must install, or the script stops with an error.
- **Uninstall.** Add `--uninstall` to remove both apps, or `--uninstall --tui` or `--uninstall --gui` to remove one. On Windows, use `-Uninstall`. Your notes and your configuration stay where they are.
- **On macOS, the desktop app updates by a new download.** Run the install script again to update it.
- **PowerShell.** Kimün detects PowerShell better, and the theme colors are right in it.
