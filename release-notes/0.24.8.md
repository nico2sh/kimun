## Kimün now has a desktop app

Kimun now has a Graphical User Interface, `kimun-gui` is a native window over the same notes, using the same `config.toml`, the same themes and the same search as the terminal app. You can use both on one workspace.

- **Flexible layout.** The views on the rail (files, find, tags, links, outline) can be dragged to another slot or to a window edge, drag the dividers to resize, and zoom the focused view to the whole window with `Ctrl+Shift+M` (`Cmd+Shift+M` on macOS). The layout is remembered. Author your own presets in `layouts.toml`.
- **Editing.** As with the TUI, you have plain editor or vim mode (nvim integration is not available for now, in consideration but not guaranteed), wikilinks, `#hashtags`, find and replace, and completion popups for `[[` links and `#` tags.
- **Around the notes.** Browse panel with preview, properties, pinned notes, sort dialog, workspace switcher (`F5`), theme picker, command palette (`Ctrl+Shift+P`), and a keyboard reference on `F1`.
- **On first run.** Just like the TUI, a short setup assistant walks you through the workspace, theme and editor.
- **Auto-updates.** The app tells you when a new version is out and can update itself when the install script put it there.

### Getting it

- **Linux and macOS:** `curl -fsSL https://kimun.2co.dev/install.sh | sh -s -- --gui`. On Linux it also adds an entry to your application menu.
- **Windows:** download `kimun-gui-0.24.8-windows-x64.zip` from this page, unzip it and run `kimun-gui.exe`. There is no installer yet, a powershell script is coming.
- **macOS app bundle:** a `.dmg` not yet.

The desktop app is new. It has had the most use on Linux; the Windows and macOS builds come from the same code and may have rough edges. Let me know if you find any issues!

## Installing

The install script now explains what to do when a build is missing for your platform, checks for the tools it needs before downloading, and handles Apple Silicon Macs running under Rosetta.
