## Better search results

Search results from Find, Ask and Semantic search now are expandable with a button, you can preview the content in the same sidebar before opening the note.

## Release signing

Every release now carries a signature. The install scripts (`install.sh`, `install-server.sh` and `install.ps1`) check it when `minisign` is installed on your computer. If the signature is wrong, the script stops. The in-app update does not check the signature yet.

## Kimün Server
Now we have explicit config for OpenRouter for embedder and LLM models, also a revamp of the configuration page so it is easier to manage.
