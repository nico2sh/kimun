## Now you can install Kimün on Windows with one command

Windows now has an installer. Open PowerShell and run:

    irm https://kimun.2co.dev/install.ps1 | iex

To install the desktop app instead, run:

    & ([scriptblock]::Create((irm https://kimun.2co.dev/install.ps1))) -Gui

The installer puts the app in `%LOCALAPPDATA%\Programs\kimun`, adds that folder to your PATH, and for the desktop app adds a Start-menu entry. It records an install marker, so the app can update itself later.

## Faster and more reliable installs and updates

The install scripts and the in-app update check now read one small file, `latest.json`, from the Kimün website. If that file cannot be read, they use the GitHub API as before, and the script prints a warning. This means a new release no longer breaks the install script in the first minutes after it is published.

The full list of commits is in the [changelog](https://github.com/nico2sh/kimun/blob/main/tui/CHANGELOG.md).
