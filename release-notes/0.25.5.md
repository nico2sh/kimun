## Images!
You can now embed images in your notes and preview them, by either directly link them with markdown images `[alt text](image path)`, including remote images (https only), or with Wiki format `![[imagefilename]]`.

## Keyboard shortcuts config
In the preferences view, you can now customize directly your keyboard shortcuts, so no more manual editing of the config file. You can export your config too, to share, reuse or whatever you want.

## Ask now finds notes by date and follows links.
- Ask can answer questions about time, such as "what did I write last week?" or "this month". It works out the dates from today and searches the notes of that period.
- If the first search is not enough, Ask can read a whole note and follow its links. It uses up to five steps for one question.
- When part of an answer comes from the model and not from your notes, the answer says so.
- The server web page shows which vault each collection belongs to.
- Indexing shows its progress on the Jobs page of the server.
